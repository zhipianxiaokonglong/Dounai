# Dounai

> 一款开源的 AI 情感助手——为孤独而有技术能力的你，提供有温度、且真正属于你自己的智能陪伴。

## ✨ 项目简介

Dounai 是一款开源的 AI 情感助手。与传统聊天助手不同，我们在提供情绪价值的同时，坚持把控制权和技术自由交还给用户：

- 🫂 **情绪价值**：带情感表达的语音交互、长期记忆、懂你所想的陪伴体验；
- 🛠 **技术能力**：多模态输入、多厂商模型接入、联网搜索、可编程提示词，一切能力对技术用户透明、可定制、可扩展；
- 🔓 **开源开放**：核心模块全部开源，可独立部署、自由组合、自行魔改。

我们相信：**陪伴不该被垄断，模型不该被锁定，数据不该被上传。**

## 🎯 目标用户

- 想要一个长期陪伴、有记忆、有温度的 AI 助手的你；
- 对技术有追求、不满足于"黑盒聊天框"的开发者与爱好者；
- 希望自主选择模型、掌控数据、深度定制的隐私敏感型用户。

## 🧩 核心特性

### 多模态输入

文字、图像、语音全模态接入，支持声纹唤醒，让交互更自然。

### 模型自由（BYOK）

- 📦 **本地免费模型**：可选安装，开箱即用，零成本体验；
- 🔑 **自选厂商**：填入你自己的 API 密钥即可接入主流大模型厂商（OpenAI、Anthropic、Gemini、DeepSeek、通义千问、Kimi、智谱、火山方舟等），或通过 OpenRouter / Ollama 等聚合与本地方案自由扩展；
- 🔀 **多模型切换**：随时切换模型，上下文不丢失，故障自动降级。

> 我们只推荐，不锁定：不提供也不代管任何 API 密钥与账户。

### 本地记忆系统

记住你的偏好、习惯与重要时刻，对话时智能唤起相关记忆，让每一次交流都建立在"记得你"的基础上。记忆带时间戳、摘要与重要性分级，完全由你查看、编辑、删除。

### 情感化表达

LLM 输出经情感分类打标，驱动带情感的语音合成——安慰时温柔，庆祝时轻快，让助手真的"有情绪"。

### 可定制人格

提示词完全开放：预设人格可更换，也可编写属于你自己的人格与提示词，后期提供可视化编辑界面。

### 桌面伴侣

轻量悬浮窗常驻桌面，随唤随到，不打扰，也不缺席。

## 🔒 隐私承诺

**你的数据只属于你。**

- 对话数据、记忆库全部**本地存储，不上传网络**；
- 声纹等生物特征**本地处理，不出设备**；
- API 密钥**仅存本地**，不代管、不上报；
- 记忆与对话支持随时**查看、导出、删除**。

## 🏗 架构概览

产品采用模块化架构，各组件可独立运行、自由组合：

| 模块 | 职责 |
|---|---|
| 输入接入层 | 文字/图像/语音处理、声纹唤醒、多厂商适配 |
| 模型编排核心 | 模型网关、提示词、联网搜索、对话存档、情感打标 |
| 记忆系统 | 本地长期记忆的检索、打包与写回 |
| 输出表达层 | 情感化 TTS、输出分流与渲染 |
| 桌面客户端 | 悬浮窗 UI 与全链路组装 |
